# emias.info

Учебный проект ЛР2 по экономике программной инженерии: сервис онлайн-записи к врачу.

Задачи ведутся в YouTrack (проект EMI), для каждой задачи заводится ветка `feature/EMI-<номер>-<описание>` (дефекты — `bugfix/...`).
Каждый коммит добавляет в каталог `progress/EMI-<номер>/` текстовый файл с однострочным описанием сделанного; переходы задачи между колонками доски сопровождаются коммитами.
По окончании спринта в master выпускается релиз (`releases/`, тег `v<версия>`).
